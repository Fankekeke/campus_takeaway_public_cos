# 基于 SpringBoot + Vue 的校园外卖平台 (Campus Takeout Platform)

点餐下单 · 商家管理 · 订单流转 · 社区论坛 · 在线沟通 · 评价互动 · 数据统计 · 双端协同

本项目是一套面向高校场景的轻量级 O2O 外卖服务平台，采用前后端分离架构，覆盖**商家管理员、用户（学生/教职工）**两类角色。系统围绕"餐品管理、订单管理、收货地址、用户评价、社区论坛、在线沟通、公告信息、数据统计"等核心业务设计，支持从用户浏览商家、选购餐品、购物车结算、在线支付、订单跟踪，到商家接单处理、餐品上下架、用户评价回复、帖子管理、数据看板的全链路数字化运营，同时融入校园社区论坛与在线沟通功能，增强用户粘性与互动体验，适用于高校食堂档口、校园周边餐饮商家、学生创业团队等场景。

## 核心特性

- **完整点餐闭环**：覆盖"浏览商家→选购餐品→购物车结算→在线支付→订单跟踪→确认收货→评价晒单"全流程，订单状态机涵盖待支付、待接单、制作中、配送中、已完成、已取消、已退款等状态，状态流转全程留痕。
- **餐品分类与热销推荐**：支持多级餐品分类管理，商家可自定义分类并配置餐品；用户端首页展示热销推荐与新品推荐，支持按分类、价格、销量、评分多维度筛选。
- **社区论坛**：内置校园社区论坛模块，用户可发布美食分享、拼单邀约、商家评价等帖子，支持点赞、评论、收藏，构建校园饮食社交生态。
- **在线即时沟通**：集成用户与商家的在线沟通功能，用户可就餐品咨询、配送问题与商家实时交流，消息记录可追溯，提升服务响应速度。
- **收货地址管理**：支持用户管理多个收货地址，针对校园场景优化地址粒度（校区→楼栋→宿舍号/教室号），可设置默认地址，下单时快速选择。
- **用户评价与商家回复**：用户完成订单后可对餐品与服务进行评分与图文评价，商家可查看并回复评价，形成"评价—回复"双向互动，差评及时响应维护口碑。
- **公告信息发布**：商家可发布店铺公告（如营业时间调整、新品上架、优惠活动），用户端首页展示最新公告，支持置顶与滚动显示。
- **数据统计看板**：商家端提供多维度数据统计，包括订单量趋势、销售额统计、热销餐品排行、用户评价分布、论坛帖子热度等，支持图表可视化展示。

## 功能模块概览

## 商家管理员端

商家管理员为店铺运营角色，负责本店铺的全方位管理与运营：

### 账号与基础

- **账户登录**：支持商家账号密码登录，首次登录需完成店铺入驻审核，支持修改密码与安全设置。
- **商家信息变更**：管理店铺基本信息，包括店铺名称、Logo、公告简介、营业时间、联系电话、配送范围、起送价、配送费，支持营业状态切换（营业中/休息中）。

### 餐品管理

- **餐品类型管理**：管理餐品分类，包括分类名称、排序、图标，支持多级分类（如主食、小吃、饮品、套餐等）。
- **餐品管理**：管理店铺餐品，包括餐品名称、图片、分类、价格、库存、描述、规格（如大份/小份、辣度选择）、上下架状态，支持批量上下架与库存预警。

### 订单管理

- **订单管理**：查看店铺全部订单，包括订单号、用户信息、餐品明细、订单金额、订单状态（待接单/制作中/配送中/已完成/已取消/已退款），支持接单、拒单、标记出餐、标记配送等操作，支持订单筛选与搜索。
- **订单支付记录**：查看订单支付详情，包括支付金额、支付方式、支付时间、支付状态，支持财务对账与导出。

### 用户与互动

- **用户信息管理**：查看在本店铺下单的用户列表，包括用户昵称、联系方式、历史订单、消费金额，支持用户标签管理。
- **用户收货地址管理**：查看用户在本店铺下单时使用的收货地址，辅助配送安排。
- **用户评价**：查看用户对本店铺餐品与服务的评价，包括评分、评价内容、图片，支持商家回复评价，维护店铺口碑。
- **用户在线沟通**：与下单用户进行实时在线沟通，回复用户关于餐品、配送、售后等问题的咨询，消息记录可追溯。

### 内容与运营

- **公告信息管理**：发布与管理店铺公告，包括公告标题、内容、类型（通知/活动/调整）、发布时间、置顶状态，支持公告编辑与删除。
- **贴子管理**：管理社区论坛中本店铺相关的帖子，包括用户发布的店铺评价帖、美食分享帖，支持回复互动、置顶优质帖子、隐藏违规帖子。
- **消息管理**：管理商家收到的各类消息，包括订单通知、用户咨询、评价提醒、系统通知，支持已读/未读管理与消息搜索。

### 数据统计

- **数据统计**：综合数据看板，展示核心经营指标（今日订单数/销售额/新增用户/评价数），支持订单趋势分析、热销餐品排行、用户消费分析、评价统计等多维度图表展示，支持报表导出。

## 用户端（学生/教职工）

用户为平台的点餐消费者，提供完整的点餐下单与社区互动功能：

### 账号与个人

- **小程序注册登录**：支持微信小程序授权登录、手机号+验证码注册登录，支持账号密码登录与找回密码，首次登录自动创建用户档案。
- **用户信息管理**：查看与编辑个人基本信息，包括昵称、头像、手机号、邮箱，支持修改密码与安全设置。
- **收货地址管理**：管理个人收货地址，包括新增、编辑、删除收货地址，针对校园场景优化地址结构（校区→楼栋→宿舍号/教室号），支持设置默认地址。

### 点餐与订单

- **公告信息查看**：浏览平台公告与商家公告，了解优惠活动、营业时间调整、新品上架等信息。
- **商家信息**：浏览商家列表，支持按距离、评分、销量排序，查看商家详情（店铺信息、营业时间、配送范围、用户评价、公告），支持收藏商家。
- **餐品详情**：查看餐品详细信息，包括图片、名称、分类、价格、库存、规格选择（辣度/份量）、描述、用户评价，支持加入购物车与立即购买。
- **热销推荐**：首页展示热销餐品推荐、新品推荐、附近商家推荐，支持个性化推荐（基于用户历史点餐偏好）。
- **我的购物车**：管理购物车中的餐品，支持修改数量、删除商品、选择规格，支持合并多家商家商品（提示分开结算），一键结算下单。
- **我的订单**：查看本人全部订单，包括订单号、商家、餐品明细、订单金额、订单状态（待付款/待接单/制作中/配送中/已完成/已取消），支持订单筛选、取消待付款订单、申请退款、确认收货。
- **订单支付**：对待付款订单进行在线支付，支持微信支付、支付宝支付、校园卡余额支付等多种方式，支付成功后自动更新订单状态并通知商家。

### 社区与沟通

- **社区论坛**：浏览校园社区论坛，包括美食分享、拼单邀约、商家评价、校园生活等版块，支持发布帖子、编辑帖子、删除自己的帖子、点赞、评论、收藏帖子。
- **商家在线沟通**：与商家进行实时在线沟通，可就餐品咨询、配送问题、售后反馈等与商家交流，消息记录可追溯，支持发送图片。
- **订单评价**：对已完成订单进行评价，包括餐品评分、服务评分、评价内容、上传图片，评价提交后不可修改，支持查看历史评价记录。
